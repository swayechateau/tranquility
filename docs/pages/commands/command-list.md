
```bash
tranquility list apps --category dev
tranquility list fonts --installed --all
tranquility list vps
tranquility list categories
```

| Option        | Description                                      |
| ------------- | ------------------------------------------------ |
| `--category`  | Filter apps by category                          |
| `--installed` | Show only installed fonts (only on fonts)        |
| `--all`       | Show both available and installed                |
